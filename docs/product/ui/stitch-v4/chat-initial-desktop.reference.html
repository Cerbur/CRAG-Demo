What are the main security protocols mentioned in the 2024 Infrastructure Manual?

person
smart_toy

According to the 2024 Infrastructure Manual, the security protocols are tiered based on data sensitivity. The core components include:

  • AES-256 Encryption: Mandatory for all data at rest within the primary database clusters.
  • Multi-Factor Authentication (MFA): Required for all SSH access to production environments.
  • Zero Trust Architecture: Implementation of micro-segmentation across the VPC to isolate critical services.
