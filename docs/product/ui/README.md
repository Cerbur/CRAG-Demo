# Web Console UI 资产

本目录保存已评审 UI 设计的可追溯导出快照，包括关键页面 PNG/PDF、设计 Token 和必要交互标注。

可编辑设计源文件保留在 Stitch。当前版本、源文件链接、页面批准状态和变更记录统一维护在 `docs/product/web-console-ui-handoff.md`。

文件命名使用 `<page>-<viewport>-v<version>.<ext>`，例如：

```text
knowledge-list-desktop-v1.png
knowledge-list-mobile-v1.png
chat-desktop-v1.png
design-tokens-v1.json
```

不要提交重复导出、工具缓存或无法追溯到交接清单版本的临时文件。
